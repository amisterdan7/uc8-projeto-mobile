# Roteiro de Teste Manual do Aplicativo Móvel (MisterFit)

## Informações do Ensaio
- **Aplicativo:** Academia MisterFit Mobile
- **Versão:** 1.0.0
- **Aparelho:** Emulador Android (Pixel 7 - API 34) / Navegador Web / Dispositivo Físico
- **Data:** 31/10/2026
- **Ambiente da API:** API MisterFit v1 (`EXPO_PUBLIC_API_URL`)
